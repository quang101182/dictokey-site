# DictoKey - Voice Accessibility for Android

**[dictokey.com](https://dictokey.com)** | **[Get it on Google Play](https://play.google.com/store/apps/details?id=com.dictokey.app)**

DictoKey is a voice typing accessibility tool for Android: write with your voice in most of your apps when typing on a
touchscreen is painful, slow or impossible. Speech recognition runs in the cloud (an internet connection is required)
and supports 51 languages.

## Key Features

- **Two independent ways to dictate**: a standard Android keyboard (screen-reader friendly) and a floating dictation bubble
- **Clean mode**: punctuation and capitals restored automatically
- **AI rewrite and real-time translation** -- speak in one language, write in another
- **Interpreter Mode** for spoken conversations between two languages
- **Works in most apps** -- sensitive apps (banking, password managers, crypto wallets) are blocked automatically
- **No account required** -- install and start dictating
- **GDPR compliant** -- no recordings stored, no ads
