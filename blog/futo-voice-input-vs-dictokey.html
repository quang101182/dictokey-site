FUTO Voice Input vs DictoKey: On-Device or Cloud?

Published October 30, 2026 · DictoKey Team · 6 min read

Short answer. FUTO Voice Input is the better pick if you want dictation that runs on the phone itself, with public source code and a one-time license. DictoKey is the better pick if you want to keep Gboard or the Samsung Keyboard, dictate from a floating bubble, and have punctuation, rewriting and translation handled for you in 51 languages, at the cost of needing an internet connection.

→ Get DictoKey on Google Play (free plan: 30 dictations per day; internet connection required).

These two apps solve different problems. FUTO describes Voice Input as an app that does speech-to-text on Android and integrates with third-party keyboards or apps that use the generic speech-to-text interfaces. DictoKey is a voice-to-text accessibility tool: a voice keyboard plus a floating bubble, built for people for whom typing on a touchscreen is painful, slow or unreliable.

What FUTO Voice Input does well

Its main strength is privacy by design. FUTO's page says the app is designed to work entirely on-device with no data stored, so you can dictate without a connection. The code is public on GitHub under the FUTO Source First License 1.0, and the app is distributed through Google Play, F-Droid and as a standalone APK.

It is also straightforward about its scope. Only languages with more than 1,000 training hours are offered in its interface, which is why the list is shorter than a cloud service's. FUTO notes that smaller models may perform poorly in languages with less training data, and that Chinese shows odd behavior between traditional and simplified characters.

Where FUTO Voice Input may not fit

  • Keyboard compatibility. FUTO's GitHub page lists Gboard and the Samsung Keyboard as incompatible. It is built into FUTO Keyboard and supports others such as HeliBoard, FlorisBoard, AnySoftKeyboard, Unexpected Keyboard and AOSP Keyboard. If you want to stay on Gboard or Samsung's keyboard, it will not plug in.
  • Development focus. The same page says development has largely shifted to the FUTO Keyboard app. Voice Input stays available for use with other keyboards.
  • Plain transcription. We did not find rewriting or translation described for it. Tidying a rambling message is a separate job.

What DictoKey does differently

DictoKey gives you two independent ways to dictate: a standard Android voice keyboard you can select in any text field, navigable with a screen reader, and a floating bubble that sits above most apps while you keep your usual keyboard. If one is unavailable, the other still works.

The bubble is adjustable in size, opacity and anchored position, and you can turn it on app by app. Touch the microphone to dictate; touch the language half for a menu with the dictation and translation languages. Drag the bubble onto Translate, Correct or Emojis to rework what you already wrote, and step back like on the keyboard. Clean mode restores punctuation and capital letters, and Interpreter Mode helps with spoken conversations between two languages.

The honest limits: DictoKey needs an internet connection because speech is transcribed in the cloud, and the free plan is capped at 30 dictations per day (Premium has a higher daily limit). It is GDPR compliant, stores no recordings, shows no ads, and blocks banking apps, password managers and crypto wallets automatically. Its Accessibility permission shows the bubble, inserts dictated text and reads the active field on the phone (for Previous / Next and spacing); that text is sent only when you choose Translate, Correct or Emojis, and it is not stored.

Who should pick what

  • Pick FUTO Voice Input if dictating without a connection matters most, if you value public source code, and if one of its 17 listed languages is yours. Using FUTO Keyboard makes it the simplest setup.
  • Stay with your keyboard's built-in microphone if it already works for you. Our guides on Gboard alternatives and Samsung voice typing alternatives cover those options.
  • Pick DictoKey if you want to keep Gboard or the Samsung Keyboard, need automatic punctuation, rewriting or translation, work in one of its 51 languages, or find precise taps on a keyboard toolbar difficult. See our accessibility page and the floating dictation button guide.

Frequently Asked Questions

Is FUTO Voice Input free?

FUTO's page says you can purchase a FUTO Voice Input license for a one-time payment, which is also valid for FUTO Keyboard. We did not find a price on the pages we checked, and the GitHub page does not state one either, so check the store listing. DictoKey has a free plan with a daily limit of 30 dictations at the time of writing; Premium costs about $7.50 per month, with a 7-day free trial for new subscribers.

Does FUTO Voice Input work offline?

FUTO says the app is designed to work entirely on-device with no data stored. DictoKey does not work offline: it transcribes speech in the cloud and needs an internet connection.

Is FUTO Voice Input open source?

Its GitHub page says the code is licensed under the FUTO Source First License 1.0, so the source is public. FUTO's own page links to the source code but does not call the app open source, so it is safest to describe it as source-available.

Does FUTO Voice Input work with Gboard or the Samsung Keyboard?

No. FUTO's GitHub page lists Gboard and the Samsung Keyboard as incompatible. It works with FUTO Keyboard, where voice input is built in, and with some other keyboards such as HeliBoard, FlorisBoard, AnySoftKeyboard and AOSP Keyboard. DictoKey's floating bubble sits above most apps, so you can keep the keyboard you already use.

Which one supports more languages?

FUTO's GitHub page lists 17 languages, limited to those with more than 1,000 training hours. DictoKey supports 51 languages with automatic language detection.

Can DictoKey rewrite or translate what I dictate?

Yes. DictoKey offers AI rewriting of dictated text and real-time translation, plus Clean mode, which restores punctuation and capital letters automatically. We did not find these features described for FUTO Voice Input.
