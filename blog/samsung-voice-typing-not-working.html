Samsung Voice Typing Not Working? Fixes and Alternatives

Published October 21, 2026 · DictoKey Team · 6 min read

Short answer. When voice typing stops working on a Samsung Galaxy, check the microphone permission for the keyboard, check the voice input setting in the keyboard settings, and make sure you have a working internet connection. If it still fails, DictoKey is an alternative with its own voice keyboard and a floating bubble, with Clean mode adding punctuation automatically.

On a Galaxy phone, the microphone on the keyboard is how most people dictate. When it disappears, does nothing or stalls, the fix is usually a setting rather than a broken phone. This page goes through the checks in order, using Samsung and Google help pages, and only at the end explains where another app can help. Using a Pixel or another brand? Read Gboard voice typing not working instead.

Fix 1: find the microphone on the keyboard

Samsung's support page says to open an app that uses the keyboard, then tap the Microphone icon and say what you want to type. It adds that Google voice typing is enabled by default and built into the Samsung keyboard. If you cannot see the icon, the keyboard layout or toolbar may have changed after an update; menu names and positions differ between One UI versions and models, so look through the toolbar above the keys and the keyboard settings.

Fix 2: check the keyboard's voice input setting

Samsung says that to customize voice typing you go to Settings > Language and input > On-screen keyboard and tap Google voice typing. On many phones this sits under Settings > General management > Samsung Keyboard settings instead. If voice typing is switched off or set to the wrong option, the microphone may be missing or silent.

Fix 3: check the microphone permission

Google's Android help describes how to change microphone access for one app:

  1. Open Settings and tap Apps.
  2. Tap the keyboard app (open the full app list if you do not see it).
  3. Tap Permissions, then Microphone.
  4. Choose Allow only while using the app; “Don't allow” blocks recording.

You can also check Security & privacy > Privacy > Permission manager > Microphone, and make sure Microphone access is not switched off for the whole device under Privacy controls. Menu names vary by brand and Android version.

Fix 4: check the language

Samsung explains that you can add input languages under the keyboard's Languages and types > Manage input languages, and switch by tapping the globe icon. Google's Gboard help also notes that talk-to-text does not work with every language. If the language you speak differs from the one selected, words can come out wrong or not at all.

Other steps people try

Community threads and third-party guides also suggest restarting the phone, clearing the keyboard's cache, checking for a weak connection when the keyboard stays on “Listening”, or installing Gboard as the default keyboard. We could not read these steps on an official Samsung page, so treat them as general housekeeping rather than documented fixes. Our Gboard voice typing alternative page explains the Gboard route.

Frequently Asked Questions

Why is Samsung voice typing not working on my Galaxy phone?

The usual suspects are a blocked microphone permission, voice input switched off or set to the wrong option in the keyboard settings, and a weak internet connection. Samsung's support page says Google voice typing is enabled by default and built into the Samsung keyboard, so start with the microphone permission and the keyboard's voice input setting.

Where is the microphone icon on the Samsung keyboard?

Samsung says you open an app that uses the keyboard, then tap the Microphone icon. If you cannot see it, check the keyboard settings for voice input, and be aware that the layout and menu names can differ between One UI versions and models.

How do I turn the microphone permission back on for the keyboard?

Open Settings, tap Apps, choose the keyboard app (open the full app list if needed), tap Permissions, then Microphone, and choose Allow only while using the app. Google's Android help describes these steps; names can vary by brand.

Does Samsung voice typing work without internet?

We could not confirm this on a Samsung page we could read, so we do not state it. Check the language options in your keyboard settings, and see our Samsung voice typing alternative page for what we found on offline language packs.

Does DictoKey work offline if Samsung voice typing fails?

No. DictoKey transcribes speech in the cloud and needs an internet connection. It has a free plan with a daily limit of 30 dictations, and it works with its own keyboard or a floating bubble, so it can serve as a backup on a Galaxy phone.
